Mod Scanner

Check a Claude Code plugin before you install it. The scan reads the mods, hooks, MCP servers, skills and agents a plugin ships and lists what they can do and anything that looks malicious. Nothing is executed.

Static analysis only. A clean result means no known malicious pattern was found in this exact version (see its SHA-256), not that the plugin is safe. Mods run with the same access as Claude Code itself; install only from sources you trust.
